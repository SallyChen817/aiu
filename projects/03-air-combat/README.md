# 雷霆空战

基于 HTML、CSS、JavaScript Canvas 和 Python 标准库的网页射击游戏，包含自动主炮、追踪导弹、Boss、连击、补给、星币、配色解锁与本地存档，并支持 Ollama 生成赛后点评。

## 运行

在本目录执行：

```powershell
python -X utf8 server.py
```

访问 `http://localhost:8877`。直接打开 `index.html` 也可以玩离线游戏，但不能调用 Python 提供的 AI 点评接口。浏览器和访问地址变化会使本地存档不同。

AI 点评需要本机 Ollama 和 `qwen3.5:4b`，可通过 `THUNDER_MODEL` 环境变量选择已安装模型。服务只提交本局结构化战绩；模型失败不影响游戏与积分，页面保留明确标注的规则分析。

## 操作

- 鼠标、WASD 或方向键移动；主炮自动射击。
- 空格发射追踪导弹，P/Esc 暂停；触屏支持拖动和按钮。
- W 升级武器，M 补充导弹，+ 修复装甲；85 秒后出现 Boss。
- 每 100 分结算 1 星币，可解锁配色；存档保存在当前浏览器。


## 实现与资料

`index.html`、`style.css` 负责页面；`game.js` 负责循环、绘制与交互；`core.js` 负责规则；`server.py` 提供页面和 AI 点评接口。

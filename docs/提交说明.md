# 提交说明

## 整理范围

源码按学习助手、笔识别、游戏、桌宠分为四个项目。保留核心实现、Dify 工作流及构建依赖、空库结构、训练数据与标注、两份 YOLO 权重、训练曲线、现有测试与工作日志。总览提供统一阅读入口。

整理版基于原工作文件夹建立，后续在本目录准备 GitHub 提交；原开发文件不作改写。

## 排除和脱敏

- 不收录桌面启动入口、快捷方式、编辑器配置、依赖安装目录、缓存、后台状态和运行日志。
- 不收录真实 API 配置、凭据文件、用户数据库、聊天会话及本机运行数据。
- 原 Word 日志含敏感内容，改用脱敏后的 Markdown 摘要，原二进制文件不收录。
- 实际局域网地址改为通用容器主机名；文档中的用户目录和机器路径改为占位说明。工作流的凭据引用清空，历史本地标识替换为匿名标识。
- YOLO 代码按项目路径查找文件；权重内嵌机器路径脱敏，保留张量存储。图片移除 EXIF/XMP/IPTC、注释及 PNG 文本元数据，不重新压缩图像内容。
- `localhost`、回环地址、监听通配地址和第三方公开服务地址属于代码所需的通用配置，不代表原机器的真实网络地址。

`.gitignore` 防止常见本地配置、数据库、会话和缓存混入后续 Git 提交；它不是对未来新增文件内容的自动脱敏工具。

## 必须自行配置的内容

学习助手需部署 Dify/Ollama、初始化空数据库、挂载插件可访问的数据目录、导入流程并重新绑定凭据；华小牛需安装锁定依赖并登录自己的模型账号；YOLO 需安装计算环境；游戏的 AI 点评需 Ollama 模型。各项目 README 提供具体入口。

## 检查范围

本次核对文件完整性、源码语法、结构化文件、数据集配对、图片/模型元数据、数据库空结构和文档引用；具体结果见[检查记录](检查记录.md)。原开发日志中的功能测试和联调为历史结果。本次没有使用真实账号调用外部模型、重新训练或接管摄像头，也未宣称四个项目已在全新机器完成端到端运行。

## 文件清单

`文件清单.tsv` 列出相对路径、字节数和 SHA-256，不包含本机绝对路径。清单自身不计算自身校验值；后续改动文件后校验值会变化。

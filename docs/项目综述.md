# 项目综述

本次材料围绕本地模型调用、智能体工具使用、视觉模型应用和创意交互四类实践展开。四个项目各自独立：学习助手和游戏使用 Ollama；笔识别使用 YOLO；桌宠使用 pi Agent。当前没有把四者连接成一个统一系统。

## 学习任务助手

目标是让学习问答与可持久保存的待办管理结合。Python 脚本验证 Ollama API；Dify 负责模型、节点和工具调用；网页通过 Python 后端调用 Dify API；SQLite 保存清单与任务。

写入链路是“读取真实记录 → 提取意图 → 校验对象 → 展示确认 → 用户确认 → SQLite 事务保存 → 再次查询”。新增默认未完成；取消不写入。普通学习问答和建议与写入分开。数据库版本号和操作收据用于拒绝过期提案及检查实际保存结果。

原验收记录覆盖多清单新增、追加、状态更新、取消、删除、切换和刷新保留。模型仍可能误解用户或给出矛盾回答；整机重启及实际等待确认超时的完整检查尚未完成。服务和插件需在新环境独立配置。

## YOLO 笔目标识别

使用单类别 pen 的 YOLO11-OBB 模型，以旋转框表示笔的位置和方向。保留 278 张训练图、68 张验证图及对应标注、初始权重、训练后的 best.pt、50 轮训练指标和曲线。Web 推理链路为摄像头 → OpenCV → YOLO → 标注帧 → FastAPI MJPEG 视频流。

网页提供开始、停止和画面显示；服务端使用运行机器的摄像头。实际背景与训练场景有差异，存在误检，置信度过滤不等于重新学习背景。Python + Web 已实现；Rust/ONNX 应用没有作为本次已完成成果。

## 雷霆空战

使用 Canvas 绘制射击游戏，包含移动、自动主炮、追踪导弹、敌机、Boss、补给、连击、星币及本地存档。Python 服务把结构化对局统计发送给 Ollama，生成赛后建议。规则、伤害和积分由程序计算，模型不修改游戏结果。

原记录包含自动测试和浏览器联调。当前源码目录已不含此前归档的游戏测试脚本，因此保留历史结论而不提供无法执行的测试入口。游戏尚未接入 Dify Agent 或 YOLO 控制。

## 华小牛桌宠

以 PySide6 桌宠和聊天窗口作为用户入口，通过异步 QProcess 与 pi Agent 交换 JSONL RPC 消息。自定义工具限制为列目录和读取项目文本，提供路径检查、文件大小限制、凭据过滤、调用预算和停止机制。设置与原生会话分开保存，并按项目恢复。

开发记录为 44 项测试通过、1 项因符号链接权限跳过；本地协议测试使用真实 pi 进程与显式测试服务，不等于真实外部模型联调。最近 Anthropic 请求认证失败，真实模型介绍项目的成功流程仍待完成。工具约束也不等同于操作系统沙箱。

## 工作过程与贡献

早期阶段主要完成模型选型、环境安装、API 调用和代理问题排查；随后完成 Dify 持久化修复、工具接入、多清单确认流程、视觉模型 Web 接入、游戏和桌宠实现。开发中使用 AI 辅助代码生成、方案解释、排错及测试。个人工作与 AI 分工沿用原日志说明，不将辅助生成内容表述为全部独立手写成果。

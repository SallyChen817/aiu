# 早期工作日志整理

本页根据原始 Word 工作日志整理，保留开发过程，去除了密钥、机器路径、快捷启动说明和已被现有代码替代的重复片段。完整后续进展以各项目工作日志为准。

## 2026-10-08 本地模型与 API

最初没有本地部署大模型的经验，先学习 Ollama，再结合任务需求与 AI 建议选择 qwen3.5:4b。随后编写 Python 请求本地聊天接口，要求生成三天的 Python 入门学习计划。

首次请求未成功。排查发现 Python 自动使用系统代理，而本地 Ollama 应直接连接，最终使用禁用代理的 opener 发出请求。当前可阅读学习助手目录的 test_Ollama.py，原笔记中的早期请求代码不再重复收录。

## Dify 与自己的网页

为将模型接入应用，学习并部署 WSL、Ubuntu、Docker 与 Dify，在工作台配置 Ollama 模型供应商。选择 Dify 的原因是可以通过节点组织模型和工具，并向自己的程序提供 API；知识库只是可扩展方向，不代表已经建成。

部署后，使用 Python 后端连接 Dify，完成聊天网页。随后开始研究自定义任务清单，并继续理解查询、确认和保存的原理。原笔记中的真实 API 密钥和本机登录配置均不收录。
